- Работа только внутри папки чата. Секреты в env/, без коммита и без выдачи через HTTP.

## Обоснование

Бизнес-ангел понятен залу без специализированной терминологии. Его ключевой конфликт — обещания против готовности платить — применим к разным студенческим проектам. Грантовый персонаж уже по контексту, венчурный может некорректно требовать масштаб от небольших полезных инициатив.

Главный эффект: цитата автора → точный вопрос → следующий вопрос меняется после ответа. Итог связывает пробел с маленьким действием, которое можно показать на защите.

Node без сторонних зависимостей выбран после уточнения про VPS: установка приложения не требует скачивания большого стека. Хостинг Sites не создавался. Интерфейс — тёмный кабинет с кислотным акцентом, крупные вопросы, собственная векторная иллюстрация.

## Границы

P0: живой диалог, серверный счётчик, объяснимая оценка, ошибки/лимиты, адаптивный интерфейс, README, one-pager, защита, публикация.
P1 включено: копирование/скачивание отчёта, сравнение итогов двух раундов в текущей вкладке.
Позже: голос, загрузка презентаций, аккаунты, база сессий, автоматическая аналитика. Разработка не начата до выбора концепции пользователем.

## Известные риски

- Лимиты API общие для всех зрителей, быстрый полный раунд может получить 429. При сбое шаг остаётся прежним, ответ можно повторить.
- Сессии в памяти одного процесса, не переживают его перезапуск.
- Баллы вероятностны и не доказывают истинность заявлений. Сравнение двух раундов не является результатом пользовательского исследования.
- Установка на домашний экран требует HTTPS и проверки на реальном телефоне; манифест не гарантирует одинаковое поведение всех браузеров.
- Для сдачи требуется открытый репозиторий. Внутренний локальный Git не заменяет публичную ссылку.
